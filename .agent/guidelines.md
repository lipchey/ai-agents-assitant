# ai-agents-assitant Guidelines

## 1. Tool usage
- Run npm scripts or tsc instead of raw scripts when available.
- Always use the specific sub-graph nodes for tasks.

## 2. Code style
- Use strict typing in TypeScript.
- Utilize ESM imports (e.g. `import { END } from "@langchain/langgraph";`).
- Keep formatting clean.

## 3. Operations
- Record major changes in `.agent/memory.md` under Pending / Open Context.
- Check off items in `.agent/tasks.md`.
